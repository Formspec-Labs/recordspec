# Native external attachment vector

This is public neutral test material, not Source acceptance or production authority. The fixture invokes the maintained production `protect_external_attachment`, Core signer/typed append and recipient opener. Plaintext is `input-original.bin`; identity is `native-external-047`; the recipient identifier is `fixture-reader`. The signed marker selects `trellis.external-attachment-suite1.v1`; nonce is derived from the signed original SHA and idempotency key, with no producer-local input required by the reader. The binding names exact originals; content hash names exact carried ciphertext plus tag.

The injectable fixture entropy stream fills each requested buffer with its counter byte, starting at 71 and incrementing after each fill. The first fill supplies test DEK `[71;32]`; subsequent production HPKE RNG calls consume the succeeding counter bytes. HPKE performs its own maintained key derivation and destroys ephemeral private material. `../../_keys/append047-entropy.seed` pins this test recipe. `../../_keys/append047-reader.seed` is the public X25519 recipient test seed. Production implementations must inject secure operating-system randomness, create fresh DEKs and per-wrap ephemeral keys, destroy ephemeral/private working material, and retain complete successful output for retry. This fixture exercises production APIs with deterministic test entropy; it makes no production RNG claim.

The canonical/signed/authored/append-head files are separate byte surfaces. The conformance test independently verifies the signed host event, obtains original digest/length, idempotency identity and wraps from signed fields, then opens the external body. It checks exact originals and wrong-recipient/body/wrap refusal. Replay preserves the exact body, nonce, key bag and signed event; changed preparation/protection fields conflict. Ordinary inline predecessor wrap reuse and stale preparation are refused. The atomic memory adapter is a local composition implementation, not a durable database qualification.
